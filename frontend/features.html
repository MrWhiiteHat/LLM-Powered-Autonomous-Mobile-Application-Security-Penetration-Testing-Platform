Technical Innovations

Engineered to replace rigid regular expressions and blind cloud uploads with intelligent, context-aware AST taint analysis, dynamic runtime instrumentation, and verified code diffs.

🧠

100% Offline Local LLM Reasoning

Executes quantized code LLMs (Qwen 2.5-Coder 1.5B) natively on commodity host CPU/GPU via Ollama on localhost socket. Eliminates proprietary source leaks and ensures total data sovereignty (GDPR Art. 28, HIPAA, PCI-DSS v4.0).

📚

Dual-Stream Hybrid RAG Retrieval

Indexes 2,075 curated security controls across OWASP Mobile Top 10 (2024), API Top 10, CWE, and CAPEC. Merges probabilistic BM25 with TF-IDF vector similarity via Reciprocal Rank Fusion (RRF, k=60) in under 2.4 ms.

⚡

Dynamic Binary Instrumentation (DBI)

Harnesses Frida 16.x DBI via ADB daemon bridge to intercept live runtime APIs: javax.crypto.Cipher, Keystore extraction, cleartext network sockets, SQLite queries, and automated sandbox installation/uninstallation.

🎯

89.2% Noise & False-Positive Suppression

Filters brittle regex matches through AST taint-analysis and deterministic LLM cognitive verification gates (τ = 0.80), drastically reducing developer alert fatigue from 30%+ down to 7.8%.

🛠️

Developer-Actionable Code Patches

Unlike legacy scanners that output generic OWASP web URLs, MSA v2.0 generates concrete Java/Kotlin and AndroidManifest.xml drop-in diffs demonstrating exact security fixes directly in the audit report.

🗺️

Multi-Taxonomy Attack Surface Mapping

Normalizes all detected code flaws, exported components, and endpoints into 34 ontology edges, linking each finding across OWASP Mobile M1–M10, OWASP API Top 10, CWE IDs, and NIST CVE entries.

⚖️

Automated CVSS v3.1 Risk Scoring

Calculates deterministic CVSS v3.1 vector equations (Base, Temporal, Environmental) across Attack Vector (AV), Complexity (AC), Privileges (PR), and User Interaction (UI) without arbitrary manual guesswork.
